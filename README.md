# Anicrop Studio

> ⚡ **专为二次元漫展返图流打造的高速极客工作台**  
> 运行环境：Windows 10 / 11 x64（原生暗色模式 / 纯代码渲染） | 交付形态：绿色免安装便携版

---

## 为什么会有这个项目？

在漫展拍过几千张片子的人都懂那是什么地狱体验：  
现场人挤人、光线杂乱、全是抓拍。Coser 戴着厚假发刘海、大美瞳和浓妆，相机眼部追焦经常抽风虚在呆毛或鼻梁上。拿卡回家坐在电脑前，噩梦才刚开始：

1. **肉眼验焦的体力酷刑**  
   几千张连拍，想看对焦有没有对准眼睛，只能一遍遍“双击放大 → 滚轮漫游到眼部 → 眯着眼看假发下的睫毛锐不锐 → 缩小复原 → 切下一张”。连续抓拍几十张同姿势照片，闭眼、假笑混在一起，机械重复几千次，挑完眼瞎手抽筋。
2. **官方与通用工具纯属浪费生命**  
   - **Windows 自带照片**：对 RAW（尤其佳能 CR3）的解码极其残疾，加载奇慢无比，暗部死黑、满屏爆彩噪，色彩严重失真，根本没法拿来挑图。
   - **厂商官方软件（如佳能 DPP）**：虽然能看对焦点，但架构老态龙钟、笨重卡顿，UI 像千禧年工控软件遗毒，翻两页卡一下。
   - **Lightroom / Bridge**：重型全家桶是用来精修调色的，几千张生肉导进去，光是建预览就能让 CPU 烫到缩频、风扇起飞。我们只是想在几秒钟内干掉连拍废片和脱焦片，不想等它建库半小时。
3. **“纯 RAW 党”的选图与找生肉绝境**  
   为了省卡空间或榨干相机连拍缓存，很多摄影师只拍单 RAW。但市面上根本没有一个轻巧现代的工具能秒开 RAW 挑图。更要命的是在本地挑完 JPG 后，还得人肉去机械硬盘几万张生肉堆里手动比对文件名把对应的 RAW 翻出来，纯纯浪费生命。

我们不需要臃肿的通用看图软件，我们需要的是一把**专为二次元漫展挑图打造的战术手术刀**。

## 核心实现：怎么干掉这些痛点的？

### 1. 15ms 视网膜双眼雷达（R 键瞬移锁瞳）
彻底废除手动滚轮漫游。底层内置离线 SCRFD-10G 神经感知管线（基于 ONNX Runtime，优先调度本地显卡），大长边 1280 尺度下约 15 毫秒完成面部与双眼特征点定位。  
- 按下 **`R` 键**，视口瞬间居中并放大至 **250% 原生瞳孔特写**，睫毛与美瞳有没有脱焦一秒鉴别。
- **特写视口继承**：在特写状态下切图，下一张照片直接自动对准新目标的眼睛居中，连拍素材之间“眼部绝对位置不动、仅微表情与锐度切换”，挑表情爽到飞起。

### 2. 底层二进制逆向：原厂对焦框原样还原（佳能 / 索尼）
不调用任何重型第三方库，直接在二进制流中硬解 APP1 EXIF 与 MakerNote 厂商私有数据段。  
- **佳能**：完整逆向 AFInfo2 / AFInfo3 协议，提取全域 651 个分区坐标与机内合焦位掩码（In-Focus Mask）。
- **（Alpha 3.1.0 新增）索尼**：解析 Sony MakerNote 私有 tag 区（`0x2000`–`0xB054`），核心取`0x2027` FocusLocation —— 该tag 单字段即含全图尺寸与对焦点坐标，无需外部工具。（已支持佳能全域 651 点与索尼 α 系列 ARW/JPG 原厂对焦框还原,感谢 @ENRIN233 贡献索尼对焦解析核心代码。）
- 相机在按下快门瞬间变绿合焦的对焦点，在屏幕上以绝对同源坐标原样投射出来，相机把焦点砸在眼睛还是嘴唇上一目了然。

### 3. 单趟 RAW 极速盒走读（秒开 CR3）
彻底推翻“CPU 硬解整个 RAW 像素”的笨重路线。  
- 针对现代 BMFF 架构容器（如佳能 CR3），直接走读 ISOBMFF 盒结构，按偏移步进只读取 `moov` 和 `uuid`，**从二进制中精准抽取机内内嵌的全尺寸高保真 JPEG 预览**，完全跳过数十 MB 的 `mdat` 生肉主数据。
- 单趟读盘派生出预览帧、物理方向、EXIF 及 AF 硬件框，结合 LRU 缓存，让纯 RAW 获得跟直出 JPG 完全一样的毫秒级切图翻页速度。

### 4. 零破坏 XMP 机内打星（与 DPP / Lightroom 互通）
- 键盘按下 **`0 ~ 5`** 或点击置底打星条，直接通过原子写入（写入临时文件后 `os.replace` 替换）修改文件元数据中的 XMP Rating，**绝不重编码或改动图像物理像素，保留原文件时间戳**。
- 打星结果与佳能 DPP、Lightroom、Camera Raw 100% 互认。

### 5. 机械硬盘保护型 RAW 自动分流调度器
精选完照片后，把精选目录和机械盘 RAW 源目录扔进调度器：
- 采用 **4MB 内存分块顺序流式写入**，单读取双写入，保护机械盘磁头不反复寻道。
- 自动容错大小写与色彩空间命名前缀差异（自动打通 `IMG_` 与 `_MG_`、`DSC` 前缀），秒级自动抓取对应 RAW，并在任务结束时高亮列出“缺失 RAW 的孤儿图”。

### 6. 双轨全键盘驾驶舱 & 左右独立物理分屏
- 按下 **`C` 键** 唤醒对比模式。左右两张照片的**平移漫游、缩放比例、特写状态完全物理隔离**，绝不互相拉扯。
- 键盘快捷键独立控制左图（`U`/`I`）或右图（`O`/`P`）步进，左屏 250% 特写看眼神光，右屏放全景看站姿神态，手不用碰鼠标。

### 7. 3D 拓扑神经网络 Agent 核心（IndicatorSphere）
侧栏内置纯 QPainter 绘制的三维拓扑球体（220 节点动态稀疏 K-NN 流形图），脱耦独立运行，模拟 AI 选片助手的自主思维、突触代谢与动态过载。开机自带纯内存合成的无延迟物理自检蜂鸣与模块逐级通电频闪。

## 适配情况说明

### 1. 操作系统
- **Windows 10 / Windows 11 x64**
- 纯代码内联 QSS 渲染，原生深色模式，界面随系统 DPI 自动物理缩放。

### 2. 机型与格式支持实况
- **标准直出图**：全量支持 `.jpg`、`.jpeg`、`.png`、`.webp`、`.bmp`。支持多线程预热、双眼检测、XMP 原子打星。
- **佳能 EOS R 系统（深度硬件适配）**：深度适配 `.cr3`、`.cr2` 格式，完整支持盒走读内嵌预览、EXIF 转正、651 点 AFInfo 原厂对焦框解析、XMP 打星。**实战主力测试机型覆盖 EOS R50、R6 Mark II、R5 等。**
- **主流厂商 RAW（基础预览兼容）**：支持索尼（`.arw`）、尼康（`.nef`）、大疆及通用（`.dng`）格式的内嵌全尺寸预览抽取与单趟 EXIF 跨块解析。

## 怎么用？

### 方式 A：绿色免安装便携版（推荐）
1. 去本仓库 [Releases](../../releases) 页面下载 `photoai.zip`。
2. 解压到电脑任意目录（建议英文或短路径）。
3. 双击 `AnicropStudio.exe` 即可直接起飞。*(首次启动若检测到模型缺失会自动拉取权重，纯本地运行，不上传任何隐私照片)*。

### 方式 B：源码运行
环境需求：Python 3.10+

```bash
git clone https://github.com/R4ksh4/AnicropStudio.git
cd AnicropStudio
pip install -r requirements.txt
python main.py
```

`requirements.txt`：
```text
PySide6>=6.5.0
onnxruntime>=1.16.0
opencv-python>=4.8.0
numpy>=1.24.0
```

## 全键盘战术快捷键速查

| 按键 | 动作 | 逻辑说明 |
| :--- | :--- | :--- |
| **`R`** / 双击 | **眼部自适应特写** | 智能瞬移锁定瞳孔 / 还原全景（支持视口继承） |
| **`C`** | **左右分屏对比** | 开关双窗格物理隔离对比模式 |
| **`0` ~ `5`** | **机内 XMP 打星** | `0` 为清除星级，`1~5` 写入星级（与 DPP/LR 互通） |
| **`H`** / **`X`** | **状态标记** | 画廊模式下选入暗房；暗房模式下标记剔除废片 |
| **`A`** / **`D`** | 上一张 / 下一张 | 普通单图模式切图 |
| **`U`** / **`I`** | 左屏上一张 / 下一张 | 对比模式下独立切左图 |
| **`O`** / **`P`** | 右屏上一张 / 下一张 | 对比模式下独立切右图 |
| **`↑ ↓ ← →`** | 视口平移漫游 | 纯键盘上下左右推拉当前画面 |
| **`Ctrl + 滚轮`** | 物理锚点缩放 | 严格以光标所在物理像素点为中心无损缩放 |
| **`Space`** | 沉浸全屏 | 隐藏全部工具栏进入纯净全屏验焦视野 |
| **`Esc`** | 退出全屏 / 返回画廊 | 退出当前层级 |

*(部分键位可在「系统偏好设置 → 快捷键映射」面板中自由改绑 A~Z 字母键)*
